# Rezerv Frontend Engineering Assessment

Two independent React + TypeScript + Tailwind CSS applications developed for the Rezerv Frontend Engineering Assessment.

## Project Overview

### Part 1 — UI Animation

A responsive, animated landing page built with React, TypeScript, Tailwind CSS, and Framer Motion.

### Part 2 — Reusable Data Table

A reusable, type-safe data table built from scratch with React and TypeScript, without a third-party table/grid library.

Features include sorting, pagination, expandable rows, sticky columns, and loading/error states.

## Local Development

Each application has its own `package.json` and README.

**Part 1**

```bash
cd part-1-animation
npm install
npm run dev
```

**Part 2**

```bash
cd part-2-data-table
npm install
npm run dev
```
